# 踩坑记录（都是真实遇到并解决的）

## 浏览器 profile

1. **Python Playwright 会破坏 Chrome profile 的 cookies**。用 Python 的 Chromium 内核打开由系统 Chrome 登录的 profile 后，登录态会损坏，连 Node 引擎也失效，得重新扫码。
   - 铁律：头条相关浏览器操作一律走 Node 引擎（`channel: 'chrome'`），Python 只做纯文本处理（`analyze.py`）或用 `channel='chrome'` 的系统 Chrome（`publish.py` 已设）。
2. **headless 模式头条要求重新登录**。抓取数据、发布都用有头模式（`headless: false`）。
3. **强杀脚本会损坏会话**。发布脚本收尾用 `.stop` 信号文件让它自己退出，不要强杀进程。
4. profile 路径统一：`scripts/.profile/`，或环境变量 `TOUTIAO_PROFILE`。所有脚本共用一份，一处登录处处通用。

## 发布

5. **封面路径**：发布包里的 cover 相对路径容易解析错，导致封面静默丢失。用绝对路径最稳；脚本会把相对路径按技能根目录解析。
6. **"已发布"可能是假阳性**：脚本点完发布后，弹出的是「作品同步授权」对话框，不是成功提示。末尾点「取消」只是不同步到其他平台，正文已发布。但**必须去作品管理页核实标题存在**才算数（本工具 publish.py 已默认核实）。
7. **新文章冷启动**：刚发的文章展现个位数是正常的，别急着改稿。分析器已内置保护：展现<50 且无历史快照时只提示观察 24 小时。

## 解析与互动

8. **搜索解析返回 0**：别用 `.cs-card` 数文章，那是热榜容器。要全页扫 `a[href*="/search/jump"]`，多层解包 url 参数，再按域名过滤站内作品。
9. **标题变成时间戳/视频名**：视频网格卡的标题是「00:47」「XX-视频」，用 `.text-xl` 取真实标题，并排除纯时间戳和 -视频 后缀。
10. **评论假阳性**：早期靠"输入框文本还在"判断成功，实际没发出去。改为只认评论列表项出现文本或评论计数变化（`verified: "in-list"`）。
11. **评论按钮恒 disable**：文字填进去了但提交不了，可能是账号未绑手机号/资料未完善/信用分不足，不是脚本问题。前置检查会在点击前识别并明确上报。
12. **随机数 bug**：`rand(40)` 传单个数字曾导致评论异常，rand 要接受 `[min,max]` 区间。

## 内容

13. **纯文字长文劝退读者**：正文配信息图（不是装饰图），每张只讲一件事，放在对应段落后，每篇 1-2 张为宜。
14. **自检脚本的中文数字误报**：游戏名「三角洲」被当成「三+角」量词命中，已加专名白名单。写稿时专有名词误报要加白名单，不要改正文去迁就规则。
